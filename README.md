База данных ракет (Rocket Database)

Консольное приложение на Python для управления списком ракет. Проект создан для отработки навыков работы со списками (Lists), их методами и списочными выражениями.

📌 Возможности:

· Добавление: добавление ракет в конец списка (append) и на конкретную позицию (insert).
· Удаление: удаление по названию (remove), удаление последнего элемента (pop) и полная очистка (clear).
· Сортировка: сортировка по алфавиту (sort) и в обратном порядке (reverse).
· Аналитика: подсчет общего количества и поиск конкретных ракет (count, index).
· Фильтрация: использование списочных выражений (List Comprehensions) для поиска ракет по первой букве.

🚀 Как запустить:

1. Скачайте файл main.py.
2. Запустите его в терминале: python main.py.
3. Следуйте инструкциям в консольном меню.
